# Machine_Learning
Implementación y entrenamiento de modelos de perceptrón multiclase y multicapa realizado durante el grado en Física.

#Contenido
- **Perceptrón multiclase:** clasificación de datos por clases, función de activación y convergencia
- **Perceptrón multicapa:** programación hacia delante, retropropagación del error y optimización de hiperparámetros.
- **Regresión logística:** evaluación de un modelo de regresión logística multiclase para la clasificación de caracteres.

#Librerías y Tecnologías
- Python
- NumPy, Matplotlib, Scikit-Learn
